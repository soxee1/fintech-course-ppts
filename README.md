## How to contribute

1. Name your file `Topic_Name-or-Group.pptx`, for example `Digital-RMB_Group1.pptx`. Chinese filenames are also welcome.
2. Click **Fork**, open `presentations` in your own copy, and choose **Add file → Upload files** to upload your slides and an optional PDF with the same filename stem.
3. Save your changes, then choose **Contribute → Open pull request**. Include the presentation date, topic, and presenter or group in the description.
4. Once the maintainer merges your submission, the files will be available to everyone and added to the index above.

New to GitHub? Follow the [step-by-step upload guide](./CONTRIBUTING.md). Collaborators with write access can upload directly.

## File and usage guidelines

- Accepted formats: `.pptx` and `.ppt`. An accompanying `.pdf` is welcome for online preview. Replace the existing file when updating a presentation.
- Browser uploads are limited to **25 MiB per file**. For larger files, compress images, remove embedded videos, or include a download link in your submission for the maintainer to handle.
- Only submit course materials suitable for public sharing. Copyright remains with the original authors. Credit the author and source when citing; other uses require the author's permission unless otherwise stated.
